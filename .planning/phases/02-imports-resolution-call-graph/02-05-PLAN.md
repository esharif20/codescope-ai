<objective>
Resolve the raw import records Plan 03 extracts into `ImportBinding`s, implementing D-05 (external detection),
D-06 (relative-import resolution + one-hop `__init__.py` re-export), D-07 (star-import expansion honouring a
literal `__all__`), and D-08's module-path addressing (via Plan 01's `module_path_for`). This is CS-022's import
half. Resolution happens in two passes across the WHOLE project's raw imports at once (not file-by-file in
isolation), because the `__init__.py` re-export hop for file A depends on file B's own already-resolved
bindings, and star expansion depends on the target module's full symbol list -- both of which only exist once
every file in the project has been parsed. Plan 08 (orchestrator) is the only caller that has that whole-project
view; this plan's functions take it as explicit arguments rather than discovering it themselves, so they stay
pure and unit-testable with small synthetic inputs.

Purpose: without explicit resolved/external/unresolved status on every import, the call resolver (Plan 06) has
no way to tell "this name comes from fastapi, don't trace it" from "this name comes from our own auth module,
trace it" from "we genuinely don't know" -- exactly the distinction AGENTS.md rule 4 requires.
Output: `backend/app/analysis/import_resolver.py` with `resolve_file_imports` and `resolve_reexports_and_stars`.

```python
from __future__ import annotations

from app.analysis.imports import RawImport
from app.analysis.models import ImportBinding, Symbol


def resolve_file_imports(
    raw_imports: list[RawImport],
    importing_module: str,
    symbol_table: dict[str, list[Symbol]],
) -> list[ImportBinding]:
    """Pass 1: direct, relative, and external resolution for ONE file's raw imports.

    `symbol_table` maps every module_path that exists in-repo to its Phase 1 Symbol
    list (top-level + nested). A module_path NOT present as a key means it does not
    exist in-repo -- i.e. `symbol_table.keys()` IS the source of truth for "in-repo"
    vs "external" (D-05): never a hardcoded stdlib list.

    For each (name, alias) in each RawImport:
    - Compute the target module path (absolute import: RawImport.module as-is;
      relative import: climb RawImport.relative_level packages from
      `importing_module` per the algorithm below, then append RawImport.module if
      non-empty).
    - If the target module path is not a key in `symbol_table`: status=RESOLVED_EXTERNAL,
      source_module=the computed target module path, source_name=the imported name
      (for from_import) or None (for plain import, since the whole external module is
      bound, e.g. `import os`).
    - Else (target module path IS a key -- in-repo):
      - For `kind="import"` (plain `import x` / `import x.y as z`): status=RESOLVED,
        source_module=target module path, source_name=None (the whole module is bound).
      - For `kind="from_import"` (not star): if `name` matches a Symbol.name directly
        defined at module top level in `symbol_table[target]` (parent_qualified_name is
        None): status=RESOLVED, source_module=target, source_name=name. Otherwise:
        status=UNRESOLVED (provisionally -- Pass 2 may still resolve it via the
        __init__.py re-export hop), source_module=target, source_name=name.
      - Star imports (`is_star=True`): always status=UNRESOLVED from this function
        (Pass 2 owns star expansion), source_module=target, source_name=None.
    - `imported_name` on the resulting ImportBinding = the alias if present, else the
      plain name (or module name for plain imports) -- the LOCAL name this binding
      introduces into the importing file's namespace.
    """


def resolve_reexports_and_stars(
    bindings_by_module: dict[str, list[ImportBinding]],
    symbol_table: dict[str, list[Symbol]],
    dunder_all_by_module: dict[str, list[str] | None],
) -> dict[str, list[ImportBinding]]:
    """Pass 2: one-hop __init__.py re-export resolution (D-06) + star expansion (D-07).

    `bindings_by_module` is EVERY file's Pass-1 output, keyed by that file's own
    module_path (the full project). `dunder_all_by_module` maps module_path to its
    literal `__all__` list if that module defines one as a literal list of string
    constants, else None (see `extract_dunder_all` below).

    For every still-UNRESOLVED non-star binding whose source_module is a key in
    `bindings_by_module` (i.e. an in-repo module that just didn't define the name
    directly): scan `bindings_by_module[source_module]` for a binding whose
    `imported_name == source_name` -- if found and that binding's own status is
    RESOLVED or RESOLVED_EXTERNAL, rewrite THIS binding to that status, with
    source_module/source_name copied from the hop target (one hop only -- do not
    chase a second hop even if the hop target is itself still unresolved).

    For every UNRESOLVED star-import binding (RawImport.is_star was True) whose
    source_module IS a key in `symbol_table`: expand it into one ImportBinding per
    name -- if `dunder_all_by_module[source_module]` is a non-None list, use exactly
    those names; otherwise use every top-level Symbol name in
    `symbol_table[source_module]`. Each expanded binding: imported_name=that name,
    source_module=source_module, source_name=that name, status=RESOLVED. A star
    import whose source_module is NOT in `symbol_table` (external) stays a single
    UNRESOLVED binding -- never expanded (D-05: we don't parse external packages).

    Returns a NEW dict with the same keys as `bindings_by_module`, values replaced by
    their Pass-2-resolved lists.
    """


def extract_dunder_all(source: str | bytes, file_path: str) -> list[str] | None:
    """Return the literal `__all__` list for a module if, and only if, the source
    contains exactly one module-top-level `__all__ = [...]` assignment whose list
    elements are all string literals. Anything else (no assignment, computed value,
    non-list, mixed content) returns None -- never guessed at (D-07's "literal list
    of string constants" qualifier)."""
```

Relative-import module-path climb algorithm (D-06), given `importing_module` (a module_path string from Plan
01's `module_path_for`, where an `__init__.py` file's own module_path is already its package name per D-08) and
`relative_level: int` (1 = the importing file's own current package; 2 = that package's parent; etc.):

```
own_package = importing_module  # for __init__.py files, module_path IS the package already
# for non-__init__ files, the file itself is not a package -- climb one extra level first
if not importing_module_is_init:
    own_package = importing_module.rsplit(".", 1)[0] if "." in importing_module else ""

package = own_package
for _ in range(relative_level - 1):
    package = package.rsplit(".", 1)[0] if "." in package else ""

if raw_import.module:  # e.g. "services.base" in `from ..services.base import X`
    target = f"{package}.{raw_import.module}" if package else raw_import.module
else:  # e.g. `from . import auth`
    target = package
```

Plan 08 passes `importing_module_is_init` as `file_path.endswith("__init__.py")` -- thread this through as an
explicit boolean parameter on `resolve_file_imports` (`is_init_file: bool`), do not infer it from
`importing_module` alone (an empty-string module_path is ambiguous between "root __init__.py" and "a
single-segment non-init module" without that extra bit).
