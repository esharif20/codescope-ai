`import os` / `import os, sys` -> one `import_statement` node per statement; EACH comma-separated name is a
separate child under the `name` field (so `node.children_by_field_name("name")` returns multiple nodes for
`import os, sys`). Each such child is either a `dotted_name` node (plain name, e.g. `"os"`) or an
`aliased_import` node with its own `name` field (a `dotted_name`) and `alias` field (an `identifier`), e.g.
`import os.path as p`.

`from X import Y` -> one `import_from_statement` node with:
- field `module_name`: either a `dotted_name` node (absolute import, e.g. `"app.services"`) or a
  `relative_import` node (relative import). A `relative_import` node's children are: an `import_prefix` node
  (its text is N literal `.` characters -- count them for the relative level) optionally followed by a
  `dotted_name` node for anything after the dots (e.g. `from ..services.base import X` -> `import_prefix` text
  `".."` + `dotted_name` text `"services.base"`; `from . import X` -> only `import_prefix`, no trailing
  `dotted_name`).
- field `name`: one or more `dotted_name`/`aliased_import` nodes (same shape as `import_statement` above), OR
  for `from X import *` a single unnamed child of type `wildcard_import` with NO field name at all -- detect
  the star case by scanning `node.children` for `node.type == "wildcard_import"`, not via
  `child_by_field_name`.
