Final shape of `backend/app/analysis/models.py` additions (append after the existing `ParseResult` class; do not
reorder or edit any existing class):

```python
class ResolutionStatus(str, Enum):
    RESOLVED = "resolved"
    RESOLVED_EXTERNAL = "resolved_external"
    UNRESOLVED = "unresolved"
    UNCERTAIN = "uncertain"


class ImportBinding(BaseModel):
    """One resolved or unresolved name binding introduced by an import statement."""

    imported_name: str
    source_module: str | None = None
    source_name: str | None = None
    status: ResolutionStatus
    file_path: str
    line: int


class UnresolvedCall(BaseModel):
    """A call site Phase 2 could not -- or could only ambiguously -- resolve.

    Never a graph node or edge (D-11): lives only in the separate index keyed by
    `enclosing_symbol`.
    """

    enclosing_symbol: str
    file_path: str
    line: int
    expression: str
    status: ResolutionStatus  # UNRESOLVED or UNCERTAIN only
    candidates: list[str] = Field(default_factory=list)  # populated only when status == UNCERTAIN


class ResolvedCall(BaseModel):
    """One resolved caller -> callee call site, before graph assembly (Plan 07 groups these into edges)."""

    caller: str
    callee: str
    line: int
```

`caller`/`callee`/`enclosing_symbol` are always in `module_path:qualified_name` form (D-09), e.g.
`"services.auth:AuthService.login"`. `source_module` on `ImportBinding` is a bare module path with no symbol
suffix, e.g. `"services.base"`.

Final shape of `backend/app/analysis/module_paths.py` (new file):

```python
def module_path_for(file_path: str, root: str) -> str:
    """Compute the Phase 2 module path for `file_path`, relative to `root` (D-08).

    Rules (no auto-detection; `root` is always explicit):
    - `file_path` must be inside `root` (or raise ValueError -- never silently guess).
    - Path separators relative to root become `.`.
    - A trailing `.py` suffix is stripped.
    - A file named `__init__.py` maps to its OWN containing directory's dotted path
      (the package name itself), not `<package>.__init__`.
    - The repo-root `__init__.py` (directly inside `root`) maps to `""` (the empty string),
      representing the top-level implicit package.
    """
```
