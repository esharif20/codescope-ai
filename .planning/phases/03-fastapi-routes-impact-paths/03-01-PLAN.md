<interfaces>
Create route_models.py with Pydantic BaseModels (all line fields >=1):
- RouteDeclaration: receiver_id:str (`module:variable`), handler_id:str (`module:qualified_name`), method:str (uppercase), path:str (local literal path), file_path:str, line:int (decorator), handler_line:int, handler_end_line:int.
- RouteDiagnostic: file_path:str, line:int, expression:str, reason:str.
- RouteRegistration: app_id:str, handler_id:str, method:str, path:str (effective path), declaration:RouteDeclaration, registration_evidence:list[RouteDiagnostic] (constructor/include source locations; reason describes fact).
- RouteInventory: declarations:list[RouteDeclaration]=[], registrations:list[RouteRegistration]=[], diagnostics:list[RouteDiagnostic]=[], file_statuses:dict[str,str]={}, truncated:bool=False.
- CallSiteEvidence: caller:str, callee:str, file_path:str, lines:list[int].
- ImpactPath: changed_symbol:str, route:RouteRegistration, symbols:list[str] (handler -> changed symbol), edges:list[CallSiteEvidence].
- ImpactResult: impacts:list[ImpactPath]=[], unknown_symbols:list[str]=[], truncated:bool=False.
Use Field(default_factory=...) for mutable defaults. These are analysis-internal contracts; Phase 5 still owns HTTP report schemas.

In routes.py define dataclasses RawReceiver(name:str, constructor:str, prefix:str|None, line:int), RawInclude(receiver:str, child:str, prefix:str|None, line:int), RouteSyntax(file_path:str, declarations:list[RouteDeclaration], receivers:list[RawReceiver], includes:list[RawInclude], diagnostics:list[RouteDiagnostic], binding_counts:dict[str,int], eligible_imports:list[RawImport]). binding_counts counts every module-scope binding occurrence (imports with aliases, assignment targets, function/class definitions, augmented assignments, loop/with/exception targets), including bindings inside module control flow but excluding function/class bodies. Receiver bindings and constructor imports must each have exactly one binding to count as unshadowed. eligible_imports retains complete RawImport records only for import nodes directly under the module root, preserving scope eligibility without matching merely by line number; function-local and conditional imports are excluded even when another import shares their line. file_path locates constructor/include facts even in files with no route declarations.
`extract_route_syntax(source:str|bytes, file_path:str, module_path:str) -> RouteSyntax`.
</interfaces>
