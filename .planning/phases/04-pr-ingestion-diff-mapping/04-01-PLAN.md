Contracts to create (these exact exported names are consumed by Plans 02-05):
- PullRequestRef(owner: str, repo: str, number: positive int).
- PinnedPullRequest(ref, title: str, base_repository: str, head_repository: str, target_base_sha: SHA40, analysis_base_sha: SHA40, head_sha: SHA40, changed_files: nonnegative int). Repositories are validated canonical owner/repo identifiers from public PR metadata. analysis_base_sha is the merge base; target_base_sha is PR base.sha. SHA40 is 40 lowercase hex characters.
- ChangedFile(old_path: str|None, new_path: str|None, status: Literal['added','modified','removed','renamed'], old_blob_sha: SHA40|None, new_blob_sha: SHA40|None). A rename is metadata from the immutable compare endpoint validated against both trees, never a guessed symbol rename.
- SourceReference(revision: Literal['base','head'], repository: str, commit_sha: SHA40, file_path: relative POSIX str, start_line: positive int, end_line: int >= start_line, url: str).
- ChangedSymbol(status: Literal['added','modified','removed'], symbol_id: str, kind: SymbolKind, old: SourceReference|None, new: SourceReference|None). Modified requires both; added only new; removed only old. A renamed symbol with changed identity becomes removed + added.
- MappingResult(changes: list[ChangedSymbol], unmapped_changes: list[SourceReference], diagnostics: list[str], partial: bool).
- AnalysisRequest(analysis_id: UUID, pr_url: str with max_length=2048).
- AnalysisError(code: str, message: safe str, retry_after_seconds: nonnegative int|None).
- AnalysisSummary(changed_symbols: list[ChangedSymbol], affected_routes_base: nonnegative int, affected_routes_head: nonnegative int, partial: bool, diagnostics: list[str]). This is ingestion/status summary, not Phase 5 report findings/schema.
- AnalysisStatus(analysis_id: UUID, state: Literal['pending','running','complete','error','timeout'], stage: Literal['accepted','metadata','sources','mapping','impact_base','impact_head','finished'], created_at: datetime, updated_at: datetime, revisions: PinnedPullRequest|None, summary: AnalysisSummary|None, error: AnalysisError|None). Complete requires summary and no error; error/timeout require error and no success summary. Do not invent percentage progress.
- IngestionError(Exception) carrying code, public_message, http_status and optional retry_after_seconds. Never put response bodies, repository content or tokens in public_message.
- SnapshotPair dataclass: metadata: PinnedPullRequest, base_root: Path, head_root: Path, files: list[ChangedFile], diagnostics: list[str]. Root paths are private and never serialized. Plan 02 creates an owning context manager, not this class's cleanup behavior.
