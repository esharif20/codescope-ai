Official API verification performed during planning (2026-11-01): [PR files](https://docs.github.com/en/rest/pulls/pulls#list-pull-requests-files) are paginated and limited to 3,000 files; [compare](https://docs.github.com/en/rest/commits/commits#compare-two-commits) includes files on the first page only, capped at 300, and merge_base_commit; [recursive trees](https://docs.github.com/en/rest/git/trees#get-a-tree) explicitly expose truncated and modes; [blobs](https://docs.github.com/en/rest/git/blobs#get-a-blob) support Base64 data by immutable object SHA. Our lower limits reject oversized inputs. Never depend on patch completeness or branch/raw_url/content_url supplied by PR responses.

GitHubClient(settings, transport=None, check_budget=lambda: None, remaining_seconds=lambda: 60.0): injected transport must receive only locally constructed https://api.github.com paths and a bounded timeout; provide get_json(path, query=None). Production transport uses urllib.request with redirects disabled. Tests use an in-memory fake and fake clock.
fetch_snapshots(ref, client, settings, *, check_budget=lambda: None, on_stage=lambda stage: None) -> context manager yielding SnapshotPair. It owns both temporary roots for the complete consumer lifetime. on_stage emits metadata and sources.
Budget callbacks are deliberately injected to avoid importing the runtime module and creating circular dependencies. Every network/body/decode/write unit checks the budget; Plan 04 supplies a monotonic implementation.
